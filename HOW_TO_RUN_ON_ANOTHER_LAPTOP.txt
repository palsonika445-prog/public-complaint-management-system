========================================================================
PCMS - PUBLIC COMPLAINT MANAGEMENT SYSTEM (जन शिकायत निवारण पोर्टल)
HOW TO RUN ON ANOTHER LAPTOP / दूसरे लैपटॉप पर कैसे चलाएं
========================================================================

दूसरे लैपटॉप में प्रोजेक्ट चलाने के 2 सबसे आसान तरीके हैं:

------------------------------------------------------------------------
ज़रूरी चीजें (Prerequisites - सिर्फ एक बार इंस्टॉल करना है):
------------------------------------------------------------------------
1. Python (3.10 या 3.11 या 3.12 या 3.13):
   https://www.python.org/downloads/
   *महत्वपूर्ण:* इंस्टॉल करते समय "Add Python to PATH" वाले बॉक्स पर टिक जरूर करें!

2. Node.js (LTS Version):
   https://nodejs.org/
   (डिफ़ॉल्ट सेटिंग्स के साथ Next-Next करके इंस्टॉल करें)

========================================================================
तरीका A: WINDOWS LAPTOP में 1-क्लिक में चलाना (सबसे आसान)
========================================================================
1. इस ज़िप फ़ाइल (pcms_project.zip) को पेनड्राइव से अपने लैपटॉप में कहीं भी Extract (Unzip) करें।
2. फ़ोल्डर खोलें और "run_windows.bat" पर Double Click (डबल क्लिक) करें!
3. यह स्क्रिप्ट अपने-आप बैकएंड और फ्रंटएंड शुरू कर देगी और ब्राउज़र में http://localhost:3000 खोल देगी!

========================================================================
तरीका B: मैनुअल तरीका (Windows / Mac / Linux)
========================================================================

STEP 1: Backend शुरू करें (टर्मिनल / CMD #1)
--------------------------------------------
1. टर्मिनल या Command Prompt खोलें और backend फ़ोल्डर में जाएं:
   cd pcms/backend

2. वर्चुअल एनवायरनमेंट बनाएं और एक्टिवेट करें:
   Windows में:
     python -m venv venv
     venv\Scripts\activate

   Mac / Linux में:
     python3 -m venv venv
     source venv/bin/activate

3. लाइब्रेरी इंस्टॉल करें:
   pip install -r requirements.txt

4. बैकएंड सर्वर चलाएं:
   python run.py
   (पोर्ट 5001 पर शुरू हो जाएगा)


STEP 2: Frontend शुरू करें (टर्मिनल / CMD #2 - नया टर्मिनल खोलें)
-------------------------------------------------------------
1. एक नया टर्मिनल खोलें और frontend फ़ोल्डर में जाएं:
   cd pcms/frontend

2. पैकेजेस इंस्टॉल करें:
   npm install

3. फ्रंटएंड सर्वर चलाएं:
   npm run dev

4. अब ब्राउज़र में खोलें:
   वेब पोर्टल:   http://localhost:3000
   मोबाइल ऐप:   http://localhost:3000/app
